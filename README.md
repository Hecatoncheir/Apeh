# Apeh

Приложение-компаньон для Apex Legends на Flutter. Сразу после запуска показывает текущие и следующие карты Ranked, обычного BR, Mixtape и Wildcard, когда их публикует [Apex Legends Status](https://apexlegendsstatus.com/current-map).

[Скачать Apeh для Windows x64](https://github.com/Hecatoncheir/Apeh/releases/latest/download/Apeh-Setup-x64.exe)

[Сайт Apeh](https://hecatoncheir.github.io/Apeh/) · [Интерактивный прототип](https://hecatoncheir.github.io/Apeh/app.html)

Исходники сайта и прототипа лежат в `site/`, а логотип, иконки и шрифты — в `site/assets/`. Прототип использует демонстрационные данные. Часовой пояс и напоминания сохраняются в браузере. GitHub Actions публикует сайт при изменениях в `site/` в ветке `main`.

Запустите установщик. Для обновления откройте «Карты», нажмите кнопку «Обновления Apeh» в верхней панели и выберите «Скачать и установить». Apeh проверит установщик и закроется после его запуска. Завершите установку, чтобы открыть новую версию.

```powershell
flutter pub get
flutter run -d windows
```

Нативное приложение загружает публичную страницу напрямую. Отдельный сервер и ключ для первого запуска не требуются. Apeh сохраняет последнее расписание на устройстве. Если обновление не удалось, приложение отмечает сохранённое расписание и продолжает показывать карты и отсчёт, пока действуют сохранённые интервалы. В браузерной сборке доступна демонстрация: источник не разрешает читать публичную страницу из другого домена.

На вкладке «Карты» можно выбрать пояс устройства, UTC или город. Apeh запоминает выбор и показывает в этом поясе время смены карт и обновления расписания.

Кнопка с колокольчиком на вкладке «Карты» открывает напоминания. Выберите режимы и число минут до смены. При значении 0 уведомление запланировано на момент ротации. Чтобы выключить напоминания, снимите отметки со всех режимов. Apeh планирует их по последнему известному расписанию и пересчитывает при обновлении. На Linux напоминания приходят, пока Apeh открыт. На Android точность зависит от разрешения на точные сигналы.

Кнопка со звездой на вкладке «Карты» открывает избранное. Разверните карту и отметьте нужные режимы. Можно добавить карту по названию, если её сейчас нет в расписании. Время до смены общее для избранных и обычных напоминаний.

На Windows в «Настройках» можно включить сворачивание в трей. После закрытия или сворачивания окна Apeh продолжит проверять расписание. Щёлкните по значку, чтобы вернуть окно, или выберите «Выйти из Apeh» в меню значка, чтобы завершить приложение.

Свой ключ можно получить на [портале Apex Legends Status](https://apexlegendsapi.com/auth). Нажмите значок ключа в Apeh, вставьте ключ и сохраните. Apeh хранит его в защищённом хранилище устройства и предпочитает API. При сбое API приложение пробует публичную страницу. Ключ можно удалить в том же окне настроек.

Вкладка «Легенды» показывает долю выбора в восьми группах Apex Legends Status и дневной график выбранной легенды за 30 дней до последней даты в источнике. Данные включают все игровые режимы в выборке каждой группы. Apeh запрашивает их напрямую и сохраняет последнюю загруженную версию каждой открытой группы. API-ключ для вкладки не нужен.

Вкладка «Оружие» загружает каталог [Apex Weapon Stats](https://apex-legends.ttkdb.com/en/compare) напрямую, показывает дату патча и сохраняет копию для работы без связи. Сравнение использует попадания в корпус вблизи, выбранный запас щита и базовый либо улучшенный магазин. Отсчёт начинается с первого выстрела и учитывает интервалы в очередях и работу затвора. Если боезапаса мало, Apeh сообщает, что нужна перезарядка.

Вкладка «Сборки» содержит пары оружия для трёх дистанций в BR и рекомендации по улучшениям легенд на 2-м и 3-м уровнях. Обе подборки обновляются одним выпуском. Встроенный выпуск сезона 31 Cipher доступен с первого запуска. Apeh проверяет [выпуски на GitHub Gist](https://gist.github.com/Hecatoncheir/04760e1240bdd49a7612d4ac0316665f) при первом открытии вкладки за сеанс и по кнопке «Проверить обновления». Последний принятый выпуск хранится на устройстве и открывается офлайн. В нативном приложении отдельно обновляется справочник с [apex.source.gs](https://apex.source.gs/legends/). Если данные расходятся с рекомендациями, Apeh показывает расхождение рядом с выпуском.

### Автоматическое обновление рекомендаций

«Мои сборки» хранит выбранную легенду, два оружия и улучшения 2-го и 3-го уровней на устройстве. Сравнение открывается из карточки сборки и использует каталог оружия, в том числе его сохранённую копию. На вкладках «Оружие» и «Легенды» кнопка «Что изменилось в патче» открывает сводку со ссылкой на EA. В сборках отображаются только относящиеся к ним пункты сводки.

Локальная задача Codex «Обновлять рекомендации Apeh после патчей» ежедневно сверяет патчноуты Respawn и EA с каталогом оружия и справочником улучшений. При подтверждённых изменениях она готовит полный выпуск и публикует его в существующий Gist. Задача использует установленный Dart и текущую авторизацию GitHub CLI на компьютере издателя. Игрокам достаточно открыть вкладку «Сборки».

Команда публикации использует тот же разбор данных, что и приложение, и присваивает следующий номер при изменении рекомендаций или сводки. Поле `reviewedThrough` хранит время последнего учтённого патча, а `patchSources` — ссылки на патчноуты. Чтобы обновить сводку, добавьте `patchHighlights` с названием, ссылкой на EA и списком изменений. У каждого пункта есть раздел `weapons` или `legends`, идентификатор оружия или легенды, название и краткий текст на русском и английском.

Для проверки черновика запустите `dart run bin/publish_builds.dart <файл>`. В черновике оставьте `revision` текущего опубликованного выпуска. Ключ `--publish` загружает проверенный выпуск в Gist. GitHub может отдавать предыдущий файл ещё несколько минут.

GitHub Actions собирает и публикует установщик Windows после отправки тега `vMAJOR.MINOR.PATCH`. Перед созданием тега обновите `version` в `pubspec.yaml`. Для локальной сборки Windows выполните `flutter build windows`. На Linux для системного хранилища ключей требуется [libsecret](https://pub.dev/packages/flutter_secure_storage#linux).
